# Shadow Arena: Пепел Колокола — версия 0.3 (исходный проект)

Офлайн action RPG для Android на Python/Kivy. Три сюжетные главы, три босса, 4 заклинания, экипировка, случайная добыча, уровни и 6 ветвей талантов (по 5 рангов), автосохранение, сенсорный джойстик. Добавлена оригинальная процедурная атмосферная музыка (WAV). Графика пока рисуется простыми геометрическими фигурами: это не коммерческий художественный уровень Diablo II.

## Как собрать APK, имея только телефон
1. На телефоне открой github.com и войди в аккаунт (или зарегистрируйся).
2. Создай **новый пустой репозиторий**. Для загрузки файлов удобнее включить в браузере «Версия для ПК».
3. Распакуй ZIP. Загрузить надо **содержимое папки проекта**, сохранив вложенные папки `.github/workflows/` и `assets/` (не ZIP целиком). Если мобильный интерфейс не позволяет загружать папки, воспользуйся мобильным редактором GitHub (github.dev) или приложением Git-клиента с поддержкой папок.
4. В репозитории перейди в **Actions** → **Build Android APK** → **Run workflow**. Если Actions выключены, включи их в настройках репозитория.
5. Дождись завершения сборки. Открой запуск workflow → **Artifacts** → **Shadow-Arena-Android-APK**, скачай архив и извлеки APK.
6. На Android открой APK и разреши установку из выбранного источника, если телефон попросит.

Сборка требует интернет и может завершиться ошибкой из-за изменений Android SDK/Buildozer. Готовый APK **не приложен**: сборка на Android не проверена. Не отключай системные защитные проверки Android ради установки.

## Управление
Левая часть экрана — джойстик; справа — четыре заклинания; снизу — сумка и таланты. Очки талантов начисляются при повышении уровня. На паузе можно сохранить игру.

## Проверки
Синтаксис Python проверен командой `python -m py_compile main.py`. Android-сборка, звук и реальное сенсорное управление на устройстве пока не тестировались.
